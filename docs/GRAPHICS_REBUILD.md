# Графический перезапуск (после отзывов о v0.1)

## Диагноз
В v0.1 использованы только MeshInstance3D с BoxMesh/SphereMesh/CylinderMesh, примитивные цвета без UV/normal maps и простой OpenGL Compatibility. В качестве рабочего релиза игра выглядела недопустимо. Из-за отсутствия поворота сцены персонажи также не стояли лицом к лицу. Отныне «собрался APK» не является визуальным критерием качества.

## Не использовать в финальном релизе
- Текущие процедурные кубы/цилиндры в качестве персонажей или основных панелек.
- Quaternius/Kenney low-poly-героев как финальные модели «AAA»: они допустимы для рига/проверки, но не соответствуют реалистичной драматичной стилистике.
- Показательные концепт-арты вместо реально импортированных 3D-моделей.
- Проверку синтаксиса и APK как доказательство качественной графики.
- Не лицензированные сканы / ассеты из Mortal Kombat, Adidas или Nokia.

## Лицензионно корректная цепочка получения ассетов
1. **Базовая анатомия:** MakeHuman или MPFB для Blender — созданный на основе core-assets персонаж, CC0. Проверить лицензию каждой сторонней одежды и причёски отдельно. Основа реалистичной мужской сетки, не финальный дизайн. Официальная лицензия: https://www.makehumancommunity.org/about/license.html
2. **Авторские персонажи:** Бомж — морщины, состаренная кожа, редкие зубы, спутанная борода, многослойный пуховик и лоскутная одежда с UV, нормалями, скульптурой складок. Гопник — коротко бритая/лысая голова, маленькая шапочка, натуральная кожаная куртка с молниями, спортивные брюки в белых носках, остроносые туфли. Два уникальных силуэта и материалы.
3. **Риг и движения:** Quaternius Universal Animation Library (CC0) как прототип и база для ретаргетинга. Удары довести вручную, создав читаемый contact/recovery. https://quaternius.com/packs/universalanimationlibrary.html
4. **Окружение и свет:** Poly Haven CC0 — asphalt, dirty concrete, bricks, metals, leather, roughness, normal, baked AO; фото-референсы провинциальных панельных дворов 1990-х. https://polyhaven.com/
5. **Экспорт:** Blender -> GLB/glTF -> Godot 4; проверить скелеты, импорт анимаций, материал, scale/axis и forward +Z. Выделить в сценах 3D-ресурсы как отдельные заменяемые сущности.
6. **Рендер:** перейти с Compatibility на Godot Mobile/Vulkan для S23+ после измерения и наличия реальных текстур и моделей. Не путать с Forward+ (преимущественно desktop); создавать baked/key/fill/rim lighting, отражения по roughness, glow и цветокоррекцию. Режим Mobile отличается от Compatibility; см. https://docs.godotengine.org/en/stable/tutorials/rendering/renderers.html .
7. **Оптимизация:** LOD, нормал-бейкинг, atlas, texture budgets, light bake и профилирование на **реальном** S23; целевые 60 FPS не объявлять достигнутыми без теста.

## Обязательные критерии визуальной приёмки
- На стоп-кадре **оба героя смотрят друг на друга**, лица частично видны камере (3/4), а атаки движутся вперёд вдоль боевой оси.
- Без интерфейса и спецэффектов оба героя узнаваемы только по силуэту; каждый отличается от заглушек не только цветом.
- Вблизи видны фактура кожи, волосы/борода, складки ткани и швы, блеск кожи и замша/ткань, металлические детали одежды.
- Панельки — текстурированные модели с объёмом, загрязнением, нормалями, мелкими реквизитами, светом и глубиной сцены, а не BoxMesh.
- Качественные анимации idle / walks / punch / kick / guard / hit / two supers / KO / victory, с понятным началом, контактом и восстановлением.
- GitHub Actions создаёт APK; затем обязательны настоящие screenshot/video проверки на Galaxy S23, S23 Ultra, S25 и профилирование, не только build.
- Изменения в художественном направлении показываются скриншотом/видео реальной 3D-сцены до того, как называются «готовой игрой».
