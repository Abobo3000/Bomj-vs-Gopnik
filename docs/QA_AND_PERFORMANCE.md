# QA / производительность Samsung Galaxy S23+

### Приоритет: стабильность и управление
- Режим landscape, 20:9 и 19.5:9, отсутствие обрезки UI и некорректных touch hitboxes.
- Запуск без сети, без запросов разрешений, без login.
- Два пальца одновременно: движение+удар, удержание блока+другое действие; отпускание кнопок в момент потери фокуса.
- Тесты обоих персонажей: каждый обычный удар, блок, два супера, projectile hit/miss, победа/поражение, тайм-аут и повторный бой.
- Режим ИИ: не наносит урон вне зоны контакта, не использует суперы без 40/65 энергии, не спамит невозможными атаками.
- Скрипты парсятся через Godot headless CI. Сборка ARM64 и Windows выполняется в workflow.

### Профили производительности (целевые, НЕ измеренные)
| Телефон | Базовая цель | После ассетов |
| --- | --- | --- |
| Galaxy S23 / S23+ | 60 FPS | dynamic resolution; LOD и baked lighting |
| Galaxy S23 Ultra | 60 FPS | выше внутренняя детализация |
| Galaxy S24 / S25 | 60 FPS | улучшенные тени, отражения при наличии запаса |
- Не выставлять фиктивные результаты FPS: измерения на реальных устройствах пока отсутствуют.
- Профили применять только после профилирования Godot и Android GPU Inspector.
- 15 минут непрерывного боя для проверки троттлинга и температуры.
- Фреймтайм, 1% low, draw calls, VRAM, скорость загрузки, расход батареи и потребление CPU/GPU фиксировать по телефону.
- В v0.1 сознательно выбран OpenGL Compatibility для первого надежного запуска; высококачественный Vulkan Mobile — следующий этап после smoke-тестов.
