# БОМЖ ПРОТИВ ГОПНИКА 🥊

Одиночный аркадный 3D-файтинг: провинциальная Россия 1997 года, два бойца, компьютерный противник, два суперудара у каждого. Разработка под Samsung Galaxy S23 и новее. **Неофициальный оригинальный проект; не связан с Mortal Kombat или товарными знаками Adidas/Nokia.**

## Текущее состояние
**v0.1 / first playable — исходники и автоматизация сборки.** Визуалы пока процедурные. Это работающий по замыслу вертикальный срез, **не AAA-релиз**. Фактический запуск на устройствах и Android-APK должен быть подтвержден CI/ручными тестами, прежде чем отмечать как verified.

Движок: **Godot 4.7.2**, GDScript, OpenGL Compatibility, ARM64. Все базовые 3D-элементы создаются программно, бинарные ассеты не требуются.

## Запуск на Windows / ПК
1. Скачай официальный [Godot 4.7.2](https://godotengine.org/download/archive/4.7.2-stable/).
2. Склонируй проект и открой файл `project.godot`.
3. Нажми **F6/F5** (Run Project) в редакторе. В меню выбери «Бомж» или «Гопник».
4. Управление: **A/D** или стрелки для ходьбы; **J** — удар, **K** — нога, **L** — блок; **U**/**I** — суперудары.
5. Для мобильного управления доступны кнопки прямо на экране.

## Android APK
Ветка `feat/first-playable-android` содержит workflow [Game Build](.github/workflows/game-build.yml), предназначенный для компиляции Android ARM64 debug APK и Windows EXE. После успешного выполнения в GitHub Actions открой нужный запуск и скачай artifact `BomjVsGopnik-first-playable`. Это debug-сборка, не версия для Google Play.

Ручной экспорт: Godot → Editor Settings → Export → Android: JDK 17 и Android SDK → Project → Export → Android → Export Project. Никаких платных SDK или внешних серверов игры не требуется.

## Геймплей
- Бой до двух победных раундов, каждый по 90 сек.
- 100 здоровья, 100 стамины; блок, обычные удары, адаптирующийся по дистанции CPU.
- **Бомж**: огненная отрыжка (40), кошачий десант (65).
- **Гопник**: шелуха в глаз (40), телефон-кирпич (65).
- Суперы потребляют накопленную стамину. Мультяшные кошки не получают повреждений.
