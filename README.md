# БОМЖ ПРОТИВ ГОПНИКА

Одиночный аркадный 3D-файтинг для Android. Цель — зрелищные бои на фоне провинциальной России 1990-х, два героя и компьютерный противник.

Разработка: Godot 4.7.2, GDScript. Первое направление — полностью играбельный вертикальный срез; уровень AAA рассматривается как художественный ориентир, а не уже достигнутое качество.

Основные правила: выбор Бомжа или Гопника, ИИ-оппонент, два суперприёма на бойца, общая шкала энергии, бои до двух выигранных раундов, управление с экрана и клавиатуры.

Рабочие изменения готовятся в отдельных ветках с последующей проверкой Android-сборки через GitHub Actions.
